防封说明

Anthropic 风控由 IP、付款、浏览器环境三维度交叉打分，三者同时干净与一致是长期稳号的核心

一、IP 与网络出口 核心权重最高
绝对红线
严禁漏出受限地区（CN / HK / MO / RU / BY / IR / KP），哪怕一次代理闪断回退直连、IPv6 或 UDP 53 泄露都可能触发标记。
高危
节点质量
纯净度：海外静态住宅 IP > 独享静态机房 IP > 机场解锁节点。推荐在「出口与订阅」用链式代理（机场前置 → 静态住宅 SOCKS5 落地），避免万人骑脏 IP。
关键
防地理瞬移
不要一天内美 / 日 / 欧来回切。选定出口后在「出口与订阅」点击绑定当前出口，锁死国家或固定 IPv4，并保持零 DIRECT 断网保护。
必做
二、付款与账单（Stripe 风控） 付款后 48h 高发
最稳支付路径
美区 Apple ID + iOS App Store 正规礼品卡内购订阅：由 Apple 统一代收，彻底绕开 Stripe 信用卡 BIN 与账单地址交叉审查，订完后网页 / Desktop / CLI 全端通用。
首选
实体卡 / 账单对齐
若用海外本人实体卡或 Google Play，务必确保出口 IP 国家、发卡行国家、账单邮编一致（如美区 IP + 美区卡 + 免税州地址），且扣款失败不要连续硬试。
注意
高危避坑
避开国内双币卡、被薅烂的共享虚拟卡 BIN、以及淘宝/闲鱼低价代充与成品号（上游黑卡一笔拒付即整批连坐封号）。新号建议免费正常用 1~2 天再订阅。
避坑
三、浏览器与运行环境指纹 已由 edualc 自动隔离
时区与语言强一致
出口在美国时，系统 /etc/localtime、TZ、LANG、浏览器 Intl.DateTimeFormat 与 Accept-Language 必须全部对齐为出口当地，绝不能出现“美国 IP + 东八区 zh-CN”。
已同步
全程容器内登录
Claude CLI、Claude Desktop 与网页登录必须全部在容器内完成，绝不用宿主机日常浏览器打开 claude.ai 或过 OAuth（防止宿主机 Cookie / 指纹污染与遥测旁路直连）。
强制
WebRTC 与纯净度
容器无公网网卡并禁用非代理 UDP / IPv6；不要乱装随机魔改 Canvas/WebGL 的反指纹插件，使用原生纯净 Chromium 最自然。登号前可跑 edualc browser https://fuck-claude.vercel.app/ 复核。
建议

版本与自动更新

每 6 小时自动经隔离代理检查 Claude Code CLI、Claude Desktop 与 Mihomo 最新版本，零直连泄露
